# Example run

A made-up Kickoff for a small tool, **"Quote Tracker"**: a one-page app a video production
company uses to log client quotes and see which are still waiting on a reply. Illustrative,
not real output, but in exactly the shape the skill writes.

| File | Written when | Shows |
|---|---|---|
| [`VTO.md`](VTO.md) | after the interview | Core Focus, done, non-goals, constraints |
| [`PLAN.md`](PLAN.md) | after the Same Page Meeting | the revised Rocks, each with a proof |
| [`SAME-PAGE-LOG.md`](SAME-PAGE-LOG.md) | during the meeting | Codex's findings verbatim + Claude's answer to each |

Read the log to see the point: Codex killed one Rock, found a proof that would have passed
while broken, and moved one idea to "later". The plan got smaller and better before any
code existed.
